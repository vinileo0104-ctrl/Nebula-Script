Nebula Script

Uma linguagem de script moderna, fortemente tipada e compilada para bytecode, construída do zero em C++17 com suporte a módulos e binários autónomos.

Sobre a Linguagem

O Nebula Script é uma linguagem desenvolvida para oferecer rapidez, segurança sintática e facilidade na execução de scripts. Ela combina a facilidade de escrita de linguagens como Lua e Python com a segurança de um analisador sintático estático e um gerador de bytecode de alto desempenho executado em máquina virtual (VM).

Guia de Instalação

A instalação do Nebula Script no Windows é automatizada através do instalador compresso compilado em C++.

  1. Faça o download do ficheiro install.exe clicando no botão no topo da página.
  2. Clique com o botão direito sobre o install.exe e selecione Executar como Administrador.
  3. O instalador irá:
    • Criar o diretório seguro em C:\Program Files\NebulaScript.
    • Copiar o compilador (nebula.exe) e o stub (stub.exe).
    • Adicionar o caminho ao PATH do sistema sem truncar variáveis existentes.
    • Associar as extensões de ficheiro .ns e .cns no Registro do Windows.
💡
Após a instalação, reinicie a sua linha de comandos (CMD / PowerShell) ou VS Code para utilizar o comando nebula globalmente.

Comandos da CLI

O executável da CLI (nebula) oferece ferramentas integradas de verificação, compilação e execução:

Comando Descrição
nebula -check <script.ns> Analisa o ficheiro em busca de erros de sintaxe e tipos sem gerar código.
nebula -nbc <main.ns> [-o <saida.cns>] Compila o ficheiro de entrada e os seus módulos para bytecode; -o define o caminho e o nome do ficheiro gerado.
nebula -run <ficheiro.cns> Executa um ficheiro de bytecode binário previamente compilado na VM Nebula.
nebula -build <main.ns> [-o <saida.exe>] Gera um executável autónomo; -o define o caminho e o nome do ficheiro. Ao abrir por duplo clique, a janela aguarda Enter após a execução.
nebula -version Exibe a versão atual do compilador e o número do build.

A biblioteca nebula.dll expõe uma API C para hosts C/C++ através de src/common/NebulaApi.h: nebula_check_syntax valida um fonte, nebula_compile gera bytecode (caminho de saída vazio usa o nome do fonte com extensão .cns) e nebula_run_bytecode executa um bytecode. As funções retornam 0 em caso de sucesso e um valor diferente de zero em caso de falha.

Tipos de Dados

O Nebula Script suporta tipos primitivos e tipos de interoperabilidade:

  • number: Números inteiros (ex: 10, -42).
  • float e double: Números de ponto flutuante (ex: 3.14, 0.001); em funções externas correspondem a C float e double.
  • string: Cadeias de texto delimitadas por aspas duplas (ex: "Nebula").
  • bool: Valores lógicos (true ou false).
  • handle: Ponteiro opaco recebido ou devolvido por funções externas.

Variáveis & Atribuição

A declaração de variáveis exige a especificação do tipo base seguida do nome da variável e o seu valor inicial:

// Declaração de variáveis
number total = 100
float pi = 3.14159
string nome = "Nebula Script"
bool ativo = true

// Reatribuição de variáveis existentes
total = 250

Declaração de Funções

As funções utilizam a palavra-chave fn, parâmetros tipados com a sintaxe tipo: nome e um tipo de retorno explícito indicado por ->:

fn CalcularArea(number: largura, number: altura) -> number {
    return largura * altura
}

number area = CalcularArea(10, 5)

Structs

Use struct para agrupar campos relacionados. Crie um valor passando os campos na ordem da declaração e acesse ou altere-os com ponto:

struct Pessoa {
    string nome
    number idade
}

Pessoa pessoa = Pessoa("Ana", 20)
pessoa.idade = pessoa.idade + 1
print(pessoa.nome)
print(pessoa.idade)

Os campos têm tipos explícitos e a verificação de tipos confere a quantidade e os tipos dos valores passados ao criar a struct.

Módulos com `use`

O Nebula Script suporta a modularização de código utilizando a diretiva use. Os ficheiros são importados uma única vez, prevenindo definições circulares ou duplicações no escopo global:

// arquivo: matematica.ns
fn Somar(number: a, number: b) -> number {
    return a + b
}

// arquivo: main.ns
use "matematica.ns"

number resultado = Somar(15, 20)
print("O resultado da soma é: " [resultado])

Para chamar qualquer exportação com uma assinatura conhecida, declare a função com extern fn. As DLLs devem exportar funções C (por exemplo, com extern "C" __declspec(dllexport)); a convenção suportada é C:

use "biblioteca.dll"

// int32_t somar(int32_t, int32_t)
extern fn somar(number: a, number: b) -> number

// double calcular(double, const char*)
extern fn calcular(double: valor, string: nome) -> double

// void registrar(const char*)
extern fn registrar(string: mensagem) -> void

number total = somar(10, 32)
registrar("chamada concluída")

Os tipos FFI são number (int32), float (C float), double (C double), bool (bool C), string (const char*) e handle (void*); o retorno também pode ser void. A assinatura precisa corresponder exatamente à exportação, que deve usar a convenção C/cdecl. As funções são procuradas nas DLLs importadas, da última para a primeira; os nomes precisam estar exportados sem decoração C++. Strings passadas à DLL são válidas durante a chamada. Para compilar o Nebula no MSYS2 UCRT64, instale a dependência de build com pacman -S mingw-w64-ucrt-x86_64-libffi.

Arrays & Operadores

Arrays são homogéneos e unidimensionais. Declare o tipo dos elementos, consulte o tamanho com length, leia pelo índice a partir de zero e altere elementos:

number[] tokens = [10, 20, 30]
tokens[1] = 42
number quantidade = length(tokens)
print(tokens[1])

Arrays vazios também exigem tipo explícito, por exemplo string[] nomes = []. Um índice inválido ou fora dos limites encerra a execução com erro.

Os operadores seguem precedência convencional: ! e menos unário; *, /, %; +, -; comparações (<, <=, >, >=); igualdade (==, !=); &&; e ||. Os operadores lógicos avaliam com curto-circuito.

Estruturas de Controlo

Controle o fluxo de execução utilizando expressões condicionais if/else e repetições com while ou for:

number contador = 0

while (contador < 5) {
    if (contador == 3) {
        print("Atingiu o número três!")
    } else {
        print("Contador em progresso...")
    }
    contador = contador + 1
}

O for usa inicialização, condição e incremento separados por ponto e vírgula:

for (number i = 0; i < 5; i = i + 1) {
    print(i)
}

Funções Nativas & Print

A linguagem inclui suporte nativo para saída de dados com interpolação e suspensão de execução. sleep recebe um número inteiro não negativo de milissegundos:

number pontos = 500

// Print com interpolação de variáveis usando colchetes [var]
print("Pontuação atual do jogador: " [pontos])

// Pausa a execução por 1000 milissegundos (1 segundo)
sleep(1000)
